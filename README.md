# Outlaw Archive Reimagined

أريد نسخ المشروع كاملًا من GitHub:
https://github.com/faisalshalahi305-gif/outlaw-events

انسخ كل ما هو شغال ومستخدم فعليًا: الكود، الصفحات، التصميم، الصور، النصوص والمحتوى، وقاعدة البيانات وSupabase، بحيث لا أحتاج لإعادة إدخال المحتوى أو رفع الصور.

لكن لا تنسخ الملفات القديمة أو المعطلة أو الأكواد والرموز السرية القديمة. افحص المشروع أولًا، ونظّفه من الملفات والأكواد المهملة والمكررة، وأزل أي Secrets أو مفاتيح قديمة واستخدم Environment Variables آمنة.

افحص Supabase وقاعدة البيانات بالكامل، بما فيها الجداول والعلاقات وRLS والـFunctions والـStorage والـEdge Functions، وأصلح أي أخطاء أو صلاحيات أو ثغرات موجودة.

الأهم: أصلح نظام التعديلات والاقتراحات بالكامل، خصوصًا:

خيار التعديلات ومحتواه.

الشخصيات الرئيسية.

أحداث أوت لاو الأخيرة.

خيار الاقتراحات ونظامه.

يجب أن تعرض التعديلات آخر نسخة منشورة فعلية من الموقع، مع الصور والنصوص والمحتوى الموجود حاليًا، بدل الصفحات الفارغة.

أي تعديل يرسله المستخدم لا يُنشر مباشرة، بل يظهر في قائمة التعديلات داخل لوحة التحكم السرية للمراجعة، وبعد الضغط على «حفظ» يتم تطبيقه على الموقع.

بعد ذلك اختبر المشروع كاملًا: الصفحات، الأزرار، المحتوى، الصور، تسجيل الدخول، الصلاحيات، Supabase، قاعدة البيانات، التعديلات، الاقتراحات، لوحة التحكم، الجوال وسطح المكتب.

الهدف: نسخة نظيفة ومستقلة وآمنة تعمل بالكامل، مع الحفاظ على كل المحتوى والصور والوظائف الفعلية وإصلاح المعطل منها.
